<objective>
Implement the direct solver module: a single-slice SSVI calibrator that directly optimizes all four parameters (theta, eta, gamma, rho) via bounded 4D Nelder-Mead with only the algebraic no-arb condition eta*(1+|rho|) <= 2 as hard barrier, multi-start sweep over initial (rho, eta) to avoid local minima, and a public validate_butterfly function for post-hoc butterfly arbitrage checking.

Purpose: Provide a cleaner calibration path than crude_solver -- the objective function is pure SSE (no butterfly penalty term), relying instead on the algebraic no-arb condition as a hard barrier. Butterfly validation is separated into a post-hoc check rather than baked into the optimization. Multi-start search is a first-class feature to handle the multi-modal 4D landscape.

Output: src/direct_solver.rs module with DirectCalibConfig, DirectCalibResult, SliceInput, calibrate_slice, calibrate_slice_with_prev, validate_butterfly; integration tests in tests/direct_solver.rs.
</objective>

**In src/direct_solver.rs**, add the following functions:

**1. calibrate_slice (public):**
```rust
/// Calibrate SSVI parameters to a single volatility slice via 4D Nelder-Mead.
///
/// Directly optimizes all four parameters (theta, eta, gamma, rho) without implicit theta solve.
/// The objective is pure SSE on total variance:
///   f(theta, eta, gamma, rho) = sum((w_model - w_market)^2)
///
/// The coupled no-arb condition eta*(1+|rho|) <= 2 is enforced as a hard barrier.
/// No butterfly density term is included in the objective -- use `validate_butterfly`
/// for post-hoc arbitrage checking.
///
/// Multi-start sweep over initial (rho, eta) explores the parameter space to avoid
/// local minima. The best result (lowest SSE) is returned.
pub fn calibrate_slice(
    k_slice: &[f64],
    w_market: &[f64],
    config: &DirectCalibConfig,
) -> DirectCalibResult
```

This is a thin wrapper that calls `calibrate_slice_with_prev(k_slice, w_market, config, None)`.

**2. calibrate_slice_with_prev (public, for Phase 16 sequential calibration):**
```rust
/// Core calibration logic for a single slice, with optional calendar spread penalty.
///
/// When `prev_theta` is `Some(prev)`, the objective includes:
///   lambda_calendar * max(0, prev - theta)^2
/// to penalize theta values below the previous slice's fitted theta.
pub fn calibrate_slice_with_prev(
    k_slice: &[f64],
    w_market: &[f64],
    config: &DirectCalibConfig,
    prev_theta: Option<f64>,
) -> DirectCalibResult
```

Implementation:
- Define the 4D objective function over x = [theta, eta, gamma, rho]:
  1. Check no-arb condition via ssvi::no_arbitrage_satisfied(eta, rho); if violated, return 1e10
  2. Compute model total variances: ssvi::total_variance_slice(k_slice, theta, eta, gamma, rho)
  3. Compute SSE: sum of (w_model[i] - w_market[i])^2
  4. NO butterfly penalty -- objective is pure SSE
  5. If prev_theta is Some(prev): add lambda_calendar * max(0, prev - theta)^2
  6. Return total
- Set bounds: lb = [theta_lower, eta_lower, gamma_lower, rho_lower], ub = [theta_upper, eta_upper, gamma_upper, rho_upper]
- Compute initial theta estimate from median of w_market (clamped to bounds); if prev_theta is Some(prev), use prev.max(median_w)
- Multi-start sweep: iterate over config.rho_starts x config.eta_starts grid
  - For each (rho_init, eta_init): x0 = [theta_init, eta_init.clamp(), 0.5.clamp(), rho_init.clamp()]
  - Call nelder_mead_bounded with the objective, x0, bounds, config.nelder_mead
  - Track best result (lowest objective value)
- After sweep, compute final SSE (without calendar penalty) for reporting
- Return DirectCalibResult with the best parameters

**Key design difference from crude_solver:** The objective has NO butterfly_penalty term. The only constraint is the algebraic hard barrier eta*(1+|rho|) <= 2 via ssvi::no_arbitrage_satisfied.

**butterfly_density helper (private):**
```rust
/// Butterfly density g(k) for the SSVI smile.
///
/// The no-arbitrage butterfly condition requires g(k) >= 0 for all k, where:
///   g(k) = (1 - k*w'/(2w))^2 - (w')^2/4 * (1/w + 1/4) + w''/2
///
/// Uses central finite differences for w' and w''.
fn butterfly_density(k: f64, theta: f64, eta: f64, gamma: f64, rho: f64) -> f64
```

Implementation: Same numerical approach as crude_solver.rs butterfly_density:
- Compute w = ssvi::total_variance(k, theta, eta, gamma, rho)
- If w <= 0.0, return 0.0
- Use central differences with h = 1e-5 for w' and w''
- Return g(k) = (1 - k*w'/(2*w))^2 - (w')^2/4 * (1/w + 1/4) + w''/2

**validate_butterfly function (public):**
```rust
/// Validate butterfly arbitrage absence for fitted SSVI parameters.
///
/// Evaluates the butterfly density g(k) at each point in `k_grid` and returns
/// per-point results indicating whether g(k) >= 0 (no arbitrage).
///
/// This is a post-hoc check -- the direct solver does not include butterfly
/// density in its objective. Use this to verify fitted parameters.
pub fn validate_butterfly(
    theta: f64,
    eta: f64,
    gamma: f64,
    rho: f64,
    k_grid: &[f64],
) -> Vec<ButterflyResult>
```

Implementation:
- For each k in k_grid:
  - Compute g = butterfly_density(k, theta, eta, gamma, rho)
  - Create ButterflyResult { k, g, valid: g >= 0.0 }
- Return the vector of results
