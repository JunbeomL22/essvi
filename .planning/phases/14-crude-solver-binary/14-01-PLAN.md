Create `src/bin/fit_crude.rs` with three logical sections: parse, fit, and report.

**1. CLI and main:**

```rust
fn main() {
    let args: Vec<String> = std::env::args().collect();
    if args.len() < 3 {
        eprintln!("Usage: cargo run --bin fit_crude -- <ticker> <date>");
        eprintln!("  e.g. cargo run --bin fit_crude -- spx 2026-03-07");
        std::process::exit(1);
    }
    let ticker = &args[1];
    let date = &args[2];
    let csv_path = format!("data/cboe/{}/{}.csv", ticker, date);

    println!("Parsing {}...", csv_path);
    let slices = parse_cboe(&csv_path);
    println!("Found {} expiry slices\n", slices.len());

    let results = fit_surface(&slices);
    println!("\nFitted {} slices successfully", results.len());

    report(&results, ticker, date);
}
```

**2. parse_cboe function:**

Parse the CBOE CSV into grouped slices. The CSV has columns: `quote_date`, `expiry`, `strike`, `underlying_price`, `c_bid`, `c_ask`, `c_iv`, `p_bid`, `p_ask`, `p_iv`, `combined_futures`, `log_moneyness`, `dte`, `total_variance`.

For the crude solver, we work directly in total variance space (not IV), so extract `log_moneyness` and `total_variance` columns.

```rust
fn parse_cboe(path: &str) -> Vec<CrudeSlice>
```

Where `CrudeSlice` is a local struct:
```rust
struct CrudeSlice {
    t: f64,        // time to expiry = dte / 365
    k: Vec<f64>,   // log-moneyness values, sorted ascending
    w: Vec<f64>,   // market total variance values
    iv: Vec<f64>,  // implied volatility for plot labels (from p_iv/c_iv using 3-zone rule)
}
```

Implementation:
- Read the file, parse the header to find column indices for `dte`, `log_moneyness`, `total_variance`, `c_iv`, `p_iv`
- Group rows by DTE (as u32). Skip rows where DTE < 1.
- For each row, extract (log_moneyness, total_variance). Also extract IV using the same 3-zone rule as fit_cboe.rs:
  - log_m < -0.1: use p_iv
  - log_m > 0.1: use c_iv
  - otherwise: mean(p_iv, c_iv)
  - Skip rows with IV < 0.01 or total_variance <= 0 or parse failures
- For each DTE group:
  - Skip if fewer than 5 data points
  - Sort by log_moneyness ascending
  - Filter to log_moneyness range [-1.0, 1.0] (focus fitting range)
  - Skip if fewer than 5 points after filtering
  - Compute t = dte / 365.0
- Return Vec<CrudeSlice> sorted by t ascending

**3. fit_surface function:**

```rust
fn fit_surface(slices: &[CrudeSlice]) -> Vec<FitOutput>
```

Where `FitOutput` is a local struct:
```rust
struct FitOutput {
    t: f64,
    theta: f64,
    eta: f64,
    gamma: f64,
    rho: f64,
    sse: f64,
    converged: bool,
    k: Vec<f64>,
    w_market: Vec<f64>,
    iv_market: Vec<f64>,
}
```

Implementation:
- Build `Vec<SliceInput>` from the parsed slices
- Call `crude_solver::calibrate_surface(&slice_inputs, &CrudeCalibConfig::default())`
- Zip results with the input slices to create FitOutput entries
- Print a per-slice summary line during calibration:
  ```
    DTE=11d (T=0.0301): theta=0.0042, eta=0.83, gamma=0.45, rho=-0.31, SSE=1.2e-06, converged=true
  ```

**4. report function:**

```rust
fn report(results: &[FitOutput], ticker: &str, date: &str)
```

Implementation:
- Create output directory: `documents/data-plots/<ticker>_<date>_crude/`
- For each slice, generate an SVG plot using `essvi::fit_common::plot_fit`:
  - Construct a `FitResult` from the `FitOutput`. For IV-space plotting:
    - iv_market comes from the stored IV values
    - iv_fit is computed from the fitted SSVI parameters: w_fit = ssvi::total_variance_slice(&k, theta, eta, gamma, rho), then iv = sqrt(w / t)
    - phi = ssvi::phi(theta, eta, gamma)
    - no_arb_usage = eta * (1.0 + rho.abs())
    - Set calendar_violations = 0 and max_calendar_violation_bps = 0.0 (not tracked per-slice in crude solver)
    - Compute max_iv_err_bps, rmse_iv_bps, avg_price_err_bps from iv_market vs iv_fit differences
  - File path: `documents/data-plots/<ticker>_<date>_crude/fit_dte_<DTE>.svg`
  - Title format: `<TICKER> DTE=<DTE> (T=<T>) crude solver`
- Print summary table to stdout:
  ```
  === Crude Solver Results: SPX 2026-03-07 ===

  | DTE |    T    |  theta  |  eta   | gamma  |  rho   |    SSE    | converged |
  |----:|--------:|--------:|-------:|-------:|-------:|----------:|:---------:|
  |  11 | 0.0301  | 0.0042  | 0.830  | 0.450  | -0.310 |  1.2e-06  |    yes    |
  ...
  ```
- Print report path and plot directory

**Key design notes:**
- This binary uses `crude_solver::calibrate_surface` (Phase 12-13), NOT the existing `calibration::calibrate`. This is the whole point -- testing the crude solver on real data.
- The CSV has a `total_variance` column pre-computed, so we use it directly rather than converting from IV. This avoids the IV -> w -> fit -> IV round-trip error.
- We still need IV values for the SVG plots (plot_fit works in IV space), so we extract them from the CSV and also back-compute fitted IV from the fitted total variance.
- The binary reuses `fit_common::plot_fit` and `FitResult` for SVG rendering to avoid code duplication.
- No new library code is needed -- this is purely a binary that wires together existing modules.
