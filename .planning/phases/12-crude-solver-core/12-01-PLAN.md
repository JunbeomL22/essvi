<task type="auto">
  <name>Task 2: Implement calibrate_slice with 4D Nelder-Mead and butterfly penalty</name>
  <files>src/crude_solver.rs, src/lib.rs</files>
  <action>
**In src/crude_solver.rs**, add the following functions:

**1. Butterfly density function** (private helper):
The SSVI butterfly arbitrage condition requires g(k) >= 0 where:
  g(k) = (1 - k*w'(k)/(2*w(k)))^2 - w'(k)^2/4 * (1/w(k) + 1/4) + w''(k)/2

where w(k) is the total variance function.

Implement `butterfly_density(k, theta, eta, gamma, rho) -> f64` that:
- Computes w = ssvi::total_variance(k, theta, eta, gamma, rho)
- Computes w' and w'' numerically using central finite differences with h=1e-5
- Returns g(k) as defined above
- If w <= 0, returns 0.0 (degenerate, let SSE handle it)

**2. Butterfly penalty function** (private helper):
`butterfly_penalty(theta, eta, gamma, rho, k_grid: &[f64]) -> f64`
- Evaluates butterfly_density at each point in k_grid
- Sums max(0, -g(k))^2 for all points where g(k) < 0 (violation)
- Returns the total penalty

**3. calibrate_slice function** (public):
```rust
pub fn calibrate_slice(
    k_slice: &[f64],
    w_market: &[f64],
    config: &CrudeCalibConfig,
) -> CrudeCalibResult
```

Implementation:
- Build the k_penalty grid: k_penalty_n evenly spaced points from k_penalty_lo to k_penalty_hi
- Define the 4D objective function over x = [theta, eta, gamma, rho]:
  1. Compute model total variances: ssvi::total_variance_slice(k_slice, theta, eta, gamma, rho)
  2. Compute SSE: sum of (w_model[i] - w_market[i])^2
  3. Check no-arb condition eta*(1+|rho|) <= 2; if violated, return 1e10
  4. Compute butterfly penalty on the k_penalty grid
  5. Return SSE + lambda * butterfly_penalty
- Set bounds: lb = [theta_lower, eta_lower, gamma_lower, rho_lower], ub = [theta_upper, eta_upper, gamma_upper, rho_upper]
- Choose initial guess x0: theta = median of w_market (rough ATM total variance estimate), eta = 0.5, gamma = 0.5, rho = -0.3 (typical equity skew). Clamp x0 within bounds.
- Call nelder_mead_bounded with the objective, x0, bounds, and config.nelder_mead
- Extract result and return CrudeCalibResult

**In src/lib.rs**, add:
```rust
pub mod crude_solver;
```

Key design notes:
- The 4D approach does NOT use solve_theta or the implicit theta constraint from calibration.rs. Theta is a free optimization variable.
- The butterfly penalty uses numerical derivatives (central differences) rather than analytic ones for simplicity.
- The no-arb condition eta*(1+|rho|) <= 2 is enforced as a hard barrier (return 1e10) since the bounds alone don't enforce this coupled constraint.
